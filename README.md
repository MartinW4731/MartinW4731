# Hey 👋 What's up?

I'm Jianheng (Martin) Wei, an aspiring **Analytics Engineer** based in Melbourne, Australia. I'm finishing a Master of Data Science at Monash University (Nov 2026) and also hold a Bachelor of Commerce (Accounting & Finance) from UQ.

## About me

- 🔭 I build tested, layered data pipelines that turn raw data into tables analysts can trust, using dbt on Snowflake and PySpark on Databricks.
- 🧱 I work with **medallion architecture** (Bronze → Silver → Gold), incremental loads and SCD Type 2 snapshots.
- ⚙️ I like **config-driven models**: in my dbt project the gold layer is generated from a config list and a Jinja loop, so adding a join means adding one config entry instead of rewriting SQL.
- ✅ I put quality gates on every layer: automated tests for row counts, key uniqueness and value ranges.
- 📊 I came from accounting and retail data, so I check that numbers reconcile before I report them.
- 🤔 **Why Analytics Engineer?** AI can already write queries and charts quickly. The lasting value is owning the clean, tested, documented data underneath, which combines a data engineer's pipeline discipline with an analyst's focus on business meaning.

## ⭐ Featured projects

- **[Airbnb Analytics Pipeline (dbt + Snowflake)](https://github.com/MartinW4731/airbnb-dbt-snowflake-pipeline)**: ELT with bronze/silver/gold models, incremental loads, Jinja macros, a config-driven gold layer, SCD2 snapshots and data tests.
- **[Australian Road Safety Data Platform](https://github.com/MartinW4731/australian-road-safety-data-platform)**: Databricks/PySpark medallion pipeline over 200K+ crash records, orchestrated with Airflow and tested with pytest and GitHub Actions.
